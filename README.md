## Featured projects

### 🕌 Al-Islam · Quran, bayan and prayer tools
Offline-first Islamic companion app, **live on Google Play** (4.9★ from 20 reviews, 500+ installs).

- Quran with search, translation, transliteration and ayah-by-ayah audio that keeps playing in the background
- Bayan and podcast streaming from RSS feeds, with a persistent mini-player and expandable player sheet
- Location-based prayer times (Adhan.js), selectable adhan sounds, animated Qibla compass with haptics, Hijri calendar, tasbih and dhikr counters
- **Stack:** React Native · Expo (Router) · TypeScript · Tamagui · TanStack Query · Zustand

[**Get it on Google Play →**](https://play.google.com/store/apps/details?id=com.theqaaf.quran)

### 🎙️ Vocs · Local-first speech-to-text for macOS
Press a key, talk, press it again. Your words are transcribed and pasted into whatever had focus. No account, no word cap, and audio never leaves the machine.

- Transcribes while you speak, so a five-minute monologue finishes as fast as a five-second one
- 99 languages, custom dictionary, writing styles, voice commands like "scratch that", filler-word removal that never touches real words
- Optional on-device grammar model, local searchable dictation history, signed auto-updates
- **Stack:** Tauri · Rust · React 19 · TypeScript · Tailwind CSS · Zustand · SQLite

[**Download**](https://hackx-in.github.io/vocs/) · [**Source**](https://github.com/HackX-IN/vocs)

### 🕸️ Vouch · Browser tests written in plain English
Vision-first browser automation: describe what to do (`click the Login button`) and a vision model finds and interacts with the element. No CSS selectors, no XPaths, so tests survive UI refactors.

- Works with GPT-4o, Claude, Gemini or fully offline with local Ollama models
- Actor-Critic self-healing loop that retries and corrects failed steps
- Playwright underneath for a reliable browser layer, with JSON reports and session video
- **Stack:** TypeScript · Node.js · Playwright · tsup · published to npm, MIT licensed

[**npm package**](https://www.npmjs.com/package/@inamul_hasan/vouch) · [**Source**](https://github.com/HackX-IN/vouch)

## How I build

- **Modular by default:** small, reusable functions and clear boundaries, so features change without rewrites
- **Tested core logic:** unit tests on the parts that must not break
- **Secure by habit:** input validation, secrets kept out of source, least-privilege tokens
- **Documented:** OpenAPI docs for every backend route and a "How to Run" in every repo
- **Shipped through CI:** automated checks before anything reaches users
